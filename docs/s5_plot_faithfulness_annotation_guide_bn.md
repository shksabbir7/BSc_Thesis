# প্লট-ফেইথফুলনেস অ্যানোটেশন নির্দেশিকা

এই পরীক্ষায় একটি সংক্ষিপ্ত বাংলা সিনেমা-প্লট এবং সেই প্লট থেকে তৈরি একটি
response দেখানো হবে। বিচার করতে হবে response-এর plot-সংক্রান্ত তথ্য শুধু দেওয়া
প্লট দ্বারা সমর্থিত কি না। অন্য কোনো ওয়েবসাইট, চলচ্চিত্র-জ্ঞান বা অনুমান ব্যবহার
করা যাবে না। প্রত্যেকে স্বাধীনভাবে কাজ করবেন।

## Labels

- **SUPPORTED:** সব plot-সংক্রান্ত দাবি প্লট দ্বারা সমর্থিত। কেবল অনুভূতি বা
  মূল্যায়ন থাকলেও এই label প্রযোজ্য।
- **CONTRADICTED:** অন্তত একটি নির্দিষ্ট দাবি প্লটের সঙ্গে সরাসরি বিরোধী।
- **UNSUPPORTED_DETAIL:** response এমন নির্দিষ্ট চরিত্র, অভিনেতা, সম্পর্ক, ঘটনা
  বা দৃশ্য যোগ করেছে যা প্লটে নেই।
- **UNDECIDABLE:** দেওয়া প্লট থেকে নির্ভরযোগ্য সিদ্ধান্ত নেওয়া সম্ভব নয়। সন্দেহ
  হলেই এটি নয়; সত্যিই প্রয়োজনীয় তথ্য অনুপস্থিত হলে ব্যবহার করতে হবে।

`CONTRADICTED` বা `UNSUPPORTED_DETAIL` হলে response থেকে সমস্যাযুক্ত সবচেয়ে ছোট
অংশটি copy করতে হবে এবং সম্ভাব্য error type বাছতে হবে। “শেষটা দুর্বল”, “অভিনয়
ভালো” বা “গল্পটি আবেগপূর্ণ” ধরনের subjective reaction নিজে hallucination নয়।

এই audit engagement-specificity, fluency, naturalness বা overall response quality
পরিমাপ করে না। Annotator কোনো condition, target level বা model score দেখবেন না।
